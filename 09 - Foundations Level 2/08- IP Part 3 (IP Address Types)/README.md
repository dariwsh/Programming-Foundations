## 🏫 Lecture Notes (The Doctor's Way)

IP addresses can be categorized based on their scope and assignment method:
*   **Public IP Address:** Globally unique and routable on the public internet. Assigned by ISPs.
*   **Private IP Address:** Used within a private local network (LAN) and not routable on the public internet (RFC 1918 ranges like `192.168.x.x`, `10.x.x.x`, `172.16.x.x` to `172.31.x.x`).
*   **Static IP:** Manually configured and permanent.
*   **Dynamic IP:** Automatically leased by a server (DHCP) and can change periodically.

## 📝 Self-Assessment Quiz

### Questions
1. **Which IP address type can be routed over the public internet?**
   * A) Private IP
   * B) Public IP
   * C) Loopback IP
   * D) Link-Local IP

2. **Which of the following is a designated Private IP address class range?**
   * A) 192.168.0.0 to 192.168.255.255
   * B) 8.8.8.8
   * C) 142.250.0.0
   * D) 1.1.1.1

3. **What is the main difference between Static and Dynamic IP addresses?**
   * A) Static IPs are faster than Dynamic IPs.
   * B) Static IPs remain constant, while Dynamic IPs change over time.
   * C) Dynamic IPs are physically wired, and Static IPs are wireless.
   * D) Static IPs are only for IPv6.


---

<details>
<summary><b>🔍 Click to reveal the Answer Key & Explanations</b></summary>

### Answer Key
1. **B)**
   * *Explanation:* Public IP addresses are globally unique and routed across public routers on the internet backbone.
2. **A)**
   * *Explanation:* `192.168.x.x` is a standard Class C private IP range used inside home and business LANs.
3. **B)**
   * *Explanation:* Static IPs are manually hardcoded and remain fixed; dynamic IPs are leased and change dynamically.
