## 🏫 Lecture Notes (The Doctor's Way)

**XML (Extensible Markup Language)** is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
*   **Characteristics:**
    *   *Self-descriptive:* Tags are custom-defined by the user (unlike HTML which has pre-defined tags like `<h1>`, `<p>`).
    *   *Hierarchical structure:* Tree structure with parent, child, and attribute nodes.
    *   *Usage:* Extensively used for configuration files (like Maven or Android manifests) and data interchange (Web Services/SOAP).

## 📝 Self-Assessment Quiz

### Questions
1. **What makes XML different from HTML?**
   * A) XML is only read by operating systems.
   * B) XML tags are custom-defined by the user; HTML has rigid, predefined tags for styling/formatting.
   * C) HTML is case-sensitive; XML is not.
   * D) XML is binary; HTML is text.

2. **Which of the following is a valid, well-formed XML tag pair?**
   * A) <user><name>Ahmed</user></name>
   * B) <user id='12'>Ahmed</user>
   * C) <user id=12>Ahmed</user>
   * D) <user>Ahmed

3. **What is a common modern alternative to XML for API data transmission?**
   * A) CSS
   * B) SQL
   * C) JSON
   * D) Binary PDF

### Answer Key
1. **B)**
   * *Explanation:* XML defines data structure and storage; users create their own tag schemas to describe data.
2. **B)**
   * *Explanation:* Well-formed XML must have matching closed tags and quoted attributes.
3. **C)**
   * *Explanation:* JSON (JavaScript Object Notation) is a lighter, highly readable format commonly replacing XML for web APIs.
