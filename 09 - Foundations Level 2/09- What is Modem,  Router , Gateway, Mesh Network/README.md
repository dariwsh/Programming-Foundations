## 🏫 Lecture Notes (The Doctor's Way)

Connecting devices requires physical and logical hardware layer translations:
*   **Modem (Modulator-Demodulator):** Translates signals from your ISP (fiber, cable, or DSL analog waves) into digital data that your computer understands.
*   **Router:** Directs packets between different networks (e.g., your home LAN and the WAN/Internet) using routing tables.
*   **Gateway:** A network node that connects two networks using completely different protocols (acts as a protocol translator).
*   **Mesh Network:** A system of multiple Wi-Fi nodes working together to create a single, unified wireless network coverage area, eliminating dead zones.
