## 🏫 Lecture Notes (The Doctor's Way)

**IPv4 (Internet Protocol Version 4)** is the fourth version of the Internet Protocol. It is used to identify devices on a network using a logical addressing scheme.
*   **Address Length:** 32 bits (4 bytes).
*   **Notation:** Dotted-Decimal notation, separating four octets with decimals (e.g., `192.168.1.1`).
*   **Address Space:** Provides approximately $2^{32} \approx 4.3$ billion unique addresses, which are now fully depleted globally.
*   **Structure:** Composed of a Network portion and a Host portion, determined by the Subnet Mask.

   * A) 192.168.1.300
   * B) 192.168.1.25
   * C) 192:168:1:25
   * D) 2001:db8::1

3. **What is the approximate limit of unique addresses in the IPv4 address space?**
   * A) 1 million
   * B) 4.3 billion
   * C) 340 undecillion
   * D) Unlimited
