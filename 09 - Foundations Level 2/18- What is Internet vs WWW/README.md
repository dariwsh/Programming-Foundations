## 🏫 Lecture Notes (The Doctor's Way)

Although often used interchangeably, the Internet and the World Wide Web are distinct systems:
*   **The Internet (The Infrastructure):** The global hardware backbone. A massive network of networks comprising optical cables, copper wires, satellites, routers, and switches.
*   **The World Wide Web (The Service):** An application layer system of web documents, media, and resources linked by hyperlinks (URLs) and accessed via the HTTP/HTTPS protocols.
*   *Doctor's Analogy:* The Internet is the network of roads. The World Wide Web represents the cars and cargo driving on those roads.
