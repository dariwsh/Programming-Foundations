## 🏫 Lecture Notes (The Doctor's Way)

**IPv6 (Internet Protocol Version 6)** is the successor to IPv4, designed to resolve the exhaustion of the IPv4 address pool.
*   **Address Length:** 128 bits (16 bytes).
*   **Notation:** Hexadecimal notation grouped into 8 blocks separated by colons (e.g., `2001:0db8:85a3:0000:0000:8a2e:0370:7334`).
*   **Address Space:** $2^{128}$ (approx. $3.4 \times 10^{38}$ or 340 undecillion addresses).
*   **Features:** Built-in security (IPsec support), stateless address autoconfiguration (SLAAC), and elimination of the need for NAT.
