## 🏫 Lecture Notes (The Doctor's Way)

A **Web Browser** is a software client that allows users to access, retrieve, and view documents on the World Wide Web.
*   **Core Duties:**
    1.  *Fetch:* Requests documents from web servers via HTTP/HTTPS.
    2.  *Parse:* Reads and understands HTML (structure), CSS (styling), and JavaScript (interaction).
    3.  *Render:* Draws the text, layout, and images onto your screen using a rendering engine (e.g., Blink in Chrome, Gecko in Firefox, WebKit in Safari).

   * A) To establish TCP connections.
   * B) To translate domain names to IP addresses.

   * D) To store files on the server.

2. **Which engine powers Apple's Safari browser?**
   * A) Blink
   * B) Gecko
   * C) WebKit
   * D) V8

3. **Which protocol do web browsers primarily use to request web pages from servers?**
   * A) SMTP
   * B) HTTP/HTTPS
   * C) FTP
   * D) DHCP
