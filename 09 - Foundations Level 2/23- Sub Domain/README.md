## 🏫 Lecture Notes (The Doctor's Way)

A **Subdomain** is an additional part of your main domain name. It is created to organize and navigate to different sections of your website.
*   **Structure:** Appears before the Second-Level Domain.
    *   *Example:* `mail.google.com` (here, `mail` is the subdomain, `google` is the SLD, and `com` is the TLD).
*   **Usage Cases:** Often used to segregate staging/testing environments (`dev.example.com`), language editions (`es.wikipedia.org`), or distinct app sections (`shop.example.com`).

## 📝 Self-Assessment Quiz

### Questions
1. **In the address 'blog.mywebsite.com', which part is the subdomain?**
   * A) blog
   * B) mywebsite
   * C) com
   * D) mywebsite.com

2. **Which of the following is a common use case for subdomains?**
   * A) To connect a modem to a router.
   * B) To host separate modules of a site, like an online shop (shop.domain.com) or a staging environment (dev.domain.com).
   * C) To replace the need for an IP address.
   * D) To secure database files.

3. **True or False: Creating a subdomain requires registering a brand new domain name with a registrar and paying a full registration fee.**
   * A) True
   * B) False


---

<details>
<summary><b>🔍 Click to reveal the Answer Key & Explanations</b></summary>

### Answer Key
1. **A)**
   * *Explanation:* `blog` is placed before the main domain root `mywebsite.com`, making it a subdomain.
2. **B)**
   * *Explanation:* Subdomains separate logical portions of a web application while keeping the main brand domain.
3. **B)**
   * *Explanation:* Once you own a root domain, you can create unlimited subdomains for free in your DNS settings.
