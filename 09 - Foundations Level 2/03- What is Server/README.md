## 🏫 Lecture Notes (The Doctor's Way)

A **Server** is a dedicated computer or software program that provides services, data, or resources to other computers on the network, which are known as **Clients**. This interaction is called the **Client-Server Model**.
*   **Role:** Servers listen for requests over the network, process them, and send back the appropriate response.
*   **Types of Servers:**
    *   *Web Servers:* Serve web pages (HTML, CSS, JS) to browsers (e.g., Apache, Nginx).
    *   *File Servers:* Store and manage files for network users.
    *   *Database Servers:* Manage databases and process queries (e.g., MySQL, PostgreSQL).
    *   *Mail Servers:* Route and store emails (e.g., SMTP servers).
