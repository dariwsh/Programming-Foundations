## 🧠 Interactive Quiz

**Question:** Which flag is used with `fstream.open()` to open a file in write mode (overwriting existing content)?

<details>
<summary><b>Option A:</b> ios::in</summary>

❌ <b>Incorrect!</b> ios::in opens files in read mode.
</details>

<details>
<summary><b>Option B:</b> ios::out</summary>

✅ <b>Correct!</b> Correct! ios::out opens files in write mode and truncates previous data by default.
</details>

<details>
<summary><b>Option C:</b> ios::app</summary>

❌ <b>Incorrect!</b> ios::app opens files in append mode, preserving old data.
</details>

<details>
<summary><b>Option D:</b> ios::binary</summary>

❌ <b>Incorrect!</b> ios::binary opens files in binary mode but doesn't specify direction.
</details>
