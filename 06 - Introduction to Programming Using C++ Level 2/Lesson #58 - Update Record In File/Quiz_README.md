## 🧠 Interactive Quiz

**Question:** How does updating a record in a text file differ from deleting a record?

<details>
<summary><b>Option A:</b> Updating requires deleting the file entirely.</summary>

❌ <b>Incorrect!</b> We overwrite the contents, not delete the file.
</details>

<details>
<summary><b>Option B:</b> In updating, instead of setting the matched vector element to an empty string (to delete it), we set it to the new updated record content.</summary>

✅ <b>Correct!</b> Correct! The logic is identical, except we replace the old record line with the new line instead of clearing it.
</details>

<details>
<summary><b>Option C:</b> Updating is done automatically by the OS.</summary>

❌ <b>Incorrect!</b> The OS does not manage text file line database operations.
</details>

<details>
<summary><b>Option D:</b> There is no difference at all.</summary>

❌ <b>Incorrect!</b> Deletion removes the record, update modifies its contents.
</details>
