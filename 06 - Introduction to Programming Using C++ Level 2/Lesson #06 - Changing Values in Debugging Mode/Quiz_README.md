## 🧠 Interactive Quiz

**Question:** Can you change variable values while in debugging mode?

<details>
<summary><b>Option A:</b> No, variables are locked during execution.</summary>

❌ <b>Incorrect!</b> You can change them in the debugger window to test logic.
</details>

<details>
<summary><b>Option B:</b> Yes, you can edit values directly in windows like Autos, Locals, or Watch.</summary>

✅ <b>Correct!</b> Correct! The debugger allows modifying values in real-time to see how the code behaves under different states.
</details>

<details>
<summary><b>Option C:</b> Yes, but only if the variable is declared const.</summary>

❌ <b>Incorrect!</b> Const variables are read-only and cannot be changed safely.
</details>

<details>
<summary><b>Option D:</b> No, because it causes memory corruption.</summary>

❌ <b>Incorrect!</b> Modifying values is a safe debugger feature designed for testing.
</details>
