## 🧠 Interactive Quiz

**Question:** What does a pointer variable store?

<details>
<summary><b>Option A:</b> The memory address of another variable.</summary>

✅ <b>Correct!</b> Correct! Pointers are special variables that hold memory addresses as their values.
</details>

<details>
<summary><b>Option B:</b> A copy of the value of another variable.</summary>

❌ <b>Incorrect!</b> That is regular variable assignment.
</details>

<details>
<summary><b>Option C:</b> A string name of the variable.</summary>

❌ <b>Incorrect!</b> They store numeric hex addresses, not names.
</details>

<details>
<summary><b>Option D:</b> The size of the memory stack.</summary>

❌ <b>Incorrect!</b> No, they store addresses of specific objects.
</details>
