## 🧠 Interactive Quiz

**Question:** How do you correctly find the maximum value in a vector?

<details>
<summary><b>Option A:</b> Compare each element against a running maximum value initialized to the first element.</summary>

✅ <b>Correct!</b> Correct! Initialize max to the first element, iterate through the rest, and update if any element is larger.
</details>

<details>
<summary><b>Option B:</b> Sum all elements and multiply by the size.</summary>

❌ <b>Incorrect!</b> This finds a product sum, not the maximum value.
</details>

<details>
<summary><b>Option C:</b> Sort the vector and pick the first element.</summary>

❌ <b>Incorrect!</b> Sorting ascending places the minimum at the beginning, not the maximum.
</details>

<details>
<summary><b>Option D:</b> Use the vector.max() built-in function.</summary>

❌ <b>Incorrect!</b> std::vector does not have a max() member function.
</details>
