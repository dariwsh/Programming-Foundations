## 🧠 Interactive Quiz

**Question:** What does the 'Call Stack' show during debugging?

<details>
<summary><b>Option A:</b> The sequence of active function calls that led to the current breakpoint.</summary>

✅ <b>Correct!</b> Correct! The Call Stack lists functions that are currently active, showing the hierarchy of calls.
</details>

<details>
<summary><b>Option B:</b> The memory size allocated on the heap.</summary>

❌ <b>Incorrect!</b> Call Stack deals with execution sequence, not heap allocations.
</details>

<details>
<summary><b>Option C:</b> The contents of C++ standard libraries.</summary>

❌ <b>Incorrect!</b> It only shows called project functions and standard wrappers.
</details>

<details>
<summary><b>Option D:</b> All variable values.</summary>

❌ <b>Incorrect!</b> Variable values are shown in Locals or Autos, not the Call Stack.
</details>
