## 🧠 Interactive Quiz

**Question:** What is the default lifetime of an automatic variable (local non-static variable)?

<details>
<summary><b>Option A:</b> The lifetime of the program.</summary>

❌ <b>Incorrect!</b> That is the lifetime of global/static variables.
</details>

<details>
<summary><b>Option B:</b> From when the function starts until the computer is turned off.</summary>

❌ <b>Incorrect!</b> Incorrect.
</details>

<details>
<summary><b>Option C:</b> Only inside the block where it is declared; it is destroyed when the scope exits.</summary>

✅ <b>Correct!</b> Correct! Local automatic variables are created on the stack when scope starts and destroyed when scope exits.
</details>

<details>
<summary><b>Option D:</b> Only during compilation.</summary>

❌ <b>Incorrect!</b> Variables exist during runtime.
</details>
