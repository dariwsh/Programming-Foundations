## 🧠 Interactive Quiz

**Question:** What is a main advantage of std::vector over traditional static arrays?

<details>
<summary><b>Option A:</b> Vectors reside purely in register memory.</summary>

❌ <b>Incorrect!</b> Vectors reside in dynamic heap memory.
</details>

<details>
<summary><b>Option B:</b> Vectors cannot be resized.</summary>

❌ <b>Incorrect!</b> Vectors are dynamic and designed to be resized.
</details>

<details>
<summary><b>Option C:</b> Vectors manage their own memory and resize dynamically as elements are added.</summary>

✅ <b>Correct!</b> Correct! Unlike static arrays, vectors can grow and shrink in size dynamically at runtime.
</details>

<details>
<summary><b>Option D:</b> Vectors do not require any headers to use.</summary>

❌ <b>Incorrect!</b> You must include <vector> to use vectors.
</details>
