## 🧠 Interactive Quiz

**Question:** What is the difference between call-by-value and call-by-reference?

<details>
<summary><b>Option A:</b> Call-by-value copies the argument, so changes inside the function do not affect the original variable.</summary>

✅ <b>Correct!</b> Correct! In call-by-value, a local copy is modified. In call-by-reference, the function works on the original variable directly.
</details>

<details>
<summary><b>Option B:</b> Call-by-reference is slower for large structures.</summary>

❌ <b>Incorrect!</b> No, reference is faster because it avoids copying data.
</details>

<details>
<summary><b>Option C:</b> Call-by-value requires the '&' symbol.</summary>

❌ <b>Incorrect!</b> No, call-by-reference uses the '&' symbol.
</details>

<details>
<summary><b>Option D:</b> There is no functional difference.</summary>

❌ <b>Incorrect!</b> They behave completely differently regarding variable modifications.
</details>
