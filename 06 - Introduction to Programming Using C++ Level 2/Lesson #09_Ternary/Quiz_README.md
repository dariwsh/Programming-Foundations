## 🧠 Interactive Quiz

**Question:** Which of the following describes the ternary operator structure in C++?

<details>
<summary><b>Option A:</b> condition ? expression_if_true : expression_if_false;</summary>

✅ <b>Correct!</b> Correct! The ternary operator works as shorthand for an if-else statement using '?' and ':'.
</details>

<details>
<summary><b>Option B:</b> condition : expression_if_true ? expression_if_false;</summary>

❌ <b>Incorrect!</b> Incorrect syntax order. The '?' must come before ':'.
</details>

<details>
<summary><b>Option C:</b> condition ? expression_if_false : expression_if_true;</summary>

❌ <b>Incorrect!</b> Incorrect logic order. The first expression executes if true, the second if false.
</details>

<details>
<summary><b>Option D:</b> if (condition) ? true : false;</summary>

❌ <b>Incorrect!</b> You do not use the 'if' keyword with the ternary operator.
</details>
