## 🧠 Interactive Quiz

**Question:** What happens when program execution reaches a Breakpoint in the debugger?

<details>
<summary><b>Option A:</b> The program terminates and displays a syntax error.</summary>

❌ <b>Incorrect!</b> Breakpoints do not terminate programs or cause syntax errors.
</details>

<details>
<summary><b>Option B:</b> The program pauses, letting you inspect current variables in memory.</summary>

✅ <b>Correct!</b> Correct! A breakpoint temporarily pauses execution so you can inspect memory and variables.
</details>

<details>
<summary><b>Option C:</b> The compiler automatically optimizes the code.</summary>

❌ <b>Incorrect!</b> Optimization is done by the compiler, not breakpoints during debugging.
</details>

<details>
<summary><b>Option D:</b> The program runs at double speed.</summary>

❌ <b>Incorrect!</b> Breakpoints pause the program; they don't speed it up.
</details>
