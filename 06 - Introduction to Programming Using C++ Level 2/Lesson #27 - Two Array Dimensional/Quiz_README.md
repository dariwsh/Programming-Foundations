## 🧠 Interactive Quiz

**Question:** How is a two-dimensional array with 2 rows and 3 columns declared and accessed in C++?

<details>
<summary><b>Option A:</b> Declared as int arr[2, 3]; accessed as arr[1, 2];</summary>

❌ <b>Incorrect!</b> C++ does not use commas for multi-dimensional array declaration.
</details>

<details>
<summary><b>Option B:</b> Declared as int arr[2][3]; accessed as arr[1][2];</summary>

✅ <b>Correct!</b> Correct! Multi-dimensional arrays use separate brackets for each dimension in C++.
</details>

<details>
<summary><b>Option C:</b> Declared as int arr(2)(3); accessed as arr(1)(2);</summary>

❌ <b>Incorrect!</b> Parentheses are not used for static array declaration.
</details>

<details>
<summary><b>Option D:</b> Declared as int arr[3][2]; accessed as arr[2][1];</summary>

❌ <b>Incorrect!</b> This has 3 rows and 2 columns, which is opposite to the question.
</details>
