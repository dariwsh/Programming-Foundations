## 🧠 Interactive Quiz

**Question:** What is the historical meaning of the `register` keyword in C++?

<details>
<summary><b>Option A:</b> It hints to the compiler to store the variable in a CPU register for fast access.</summary>

✅ <b>Correct!</b> Correct! Historically, 'register' requested the compiler to place the variable inside CPU registers instead of RAM (deprecated/unused in modern compiler optimizations).
</details>

<details>
<summary><b>Option B:</b> It registers a function as a callback.</summary>

❌ <b>Incorrect!</b> It has nothing to do with callback registrations.
</details>

<details>
<summary><b>Option C:</b> It logs the variable inside database registers.</summary>

❌ <b>Incorrect!</b> It's a compiler instruction, not database logging.
</details>

<details>
<summary><b>Option D:</b> It forces the variable to be read-only.</summary>

❌ <b>Incorrect!</b> Read-only is done via the 'const' keyword.
</details>
