## 🧠 Interactive Quiz

**Question:** What does the Autos Window display during debugging?

<details>
<summary><b>Option A:</b> All global variables in the application.</summary>

❌ <b>Incorrect!</b> Global variables are not automatically shown in the Autos window unless used nearby.
</details>

<details>
<summary><b>Option B:</b> Variables used in the current line and the preceding few lines.</summary>

✅ <b>Correct!</b> Correct! The Autos Window automatically shows variables related to the current and nearby execution lines.
</details>

<details>
<summary><b>Option C:</b> Only values stored in the CPU registers.</summary>

❌ <b>Incorrect!</b> Autos displays high-level variables, not CPU registers directly.
</details>

<details>
<summary><b>Option D:</b> Only pointer addresses.</summary>

❌ <b>Incorrect!</b> It displays all variable types (integers, floats, objects) and their values.
</details>
