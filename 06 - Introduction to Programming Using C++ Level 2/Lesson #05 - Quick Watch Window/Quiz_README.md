## 🧠 Interactive Quiz

**Question:** What is the primary purpose of the Quick Watch Window?

<details>
<summary><b>Option A:</b> To compile the project in the background.</summary>

❌ <b>Incorrect!</b> Quick Watch is a debugging utility, not a compiler feature.
</details>

<details>
<summary><b>Option B:</b> To format the C++ source code.</summary>

❌ <b>Incorrect!</b> Quick Watch doesn't edit or format code.
</details>

<details>
<summary><b>Option C:</b> To evaluate a specific expression or inspect a single variable instantly during pause.</summary>

✅ <b>Correct!</b> Correct! Quick Watch provides a quick dialog to check variable values or evaluate expressions on the fly.
</details>

<details>
<summary><b>Option D:</b> To list all files in the current solution.</summary>

❌ <b>Incorrect!</b> File navigation is done in Solution Explorer, not Quick Watch.
</details>
