## 🧠 Interactive Quiz

**Question:** What header file must be included to use `std::setw`?

<details>
<summary><b>Option A:</b> <iostream></summary>

❌ <b>Incorrect!</b> <iostream> has standard stream variables, but manipulators like setw require <iomanip>.
</details>

<details>
<summary><b>Option B:</b> <iomanip></summary>

✅ <b>Correct!</b> Correct! The <iomanip> header contains input/output parametric manipulators including std::setw.
</details>

<details>
<summary><b>Option C:</b> <string></summary>

❌ <b>Incorrect!</b> No, <string> is for string operations.
</details>

<details>
<summary><b>Option D:</b> <cmath></summary>

❌ <b>Incorrect!</b> No, <cmath> contains math functions.
</details>
