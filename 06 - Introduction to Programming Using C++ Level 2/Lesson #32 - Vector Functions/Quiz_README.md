## 🧠 Interactive Quiz

**Question:** What does the `v.empty()` method return if the vector has elements inside it?

<details>
<summary><b>Option A:</b> true</summary>

❌ <b>Incorrect!</b> empty() returns true only if size is 0.
</details>

<details>
<summary><b>Option B:</b> false</summary>

✅ <b>Correct!</b> Correct! empty() returns false (0) if the vector contains one or more elements.
</details>

<details>
<summary><b>Option C:</b> 0x00 (Null pointer)</summary>

❌ <b>Incorrect!</b> It returns a bool, not a pointer.
</details>

<details>
<summary><b>Option D:</b> An error.</summary>

❌ <b>Incorrect!</b> Calling empty() on a non-empty vector is safe.
</details>
