## 🧠 Interactive Quiz

**Question:** Which tm structure member represents the days elapsed since Sunday (0-6)?

<details>
<summary><b>Option A:</b> tm_yday</summary>

❌ <b>Incorrect!</b> tm_yday represents days since January 1st (0-365).
</details>

<details>
<summary><b>Option B:</b> tm_wday</summary>

✅ <b>Correct!</b> Correct! tm_wday represents weekdays, starting from 0 (Sunday) to 6 (Saturday).
</details>

<details>
<summary><b>Option C:</b> tm_mday</summary>

❌ <b>Incorrect!</b> tm_mday represents the day of the month (1-31).
</details>

<details>
<summary><b>Option D:</b> tm_day</summary>

❌ <b>Incorrect!</b> There is no member named tm_day; it is tm_mday or tm_wday.
</details>
