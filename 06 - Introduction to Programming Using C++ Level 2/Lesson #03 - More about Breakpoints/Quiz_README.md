## 🧠 Interactive Quiz

**Question:** Why is placing a breakpoint inside a loop especially useful?

<details>
<summary><b>Option A:</b> It speeds up loop compilation.</summary>

❌ <b>Incorrect!</b> Debugging slows down execution and doesn't affect compilation speed.
</details>

<details>
<summary><b>Option B:</b> It automatically converts the loop into a recursive function.</summary>

❌ <b>Incorrect!</b> Debuggers do not change code logic.
</details>

<details>
<summary><b>Option C:</b> It lets you inspect variable changes and iteration state on every loop cycle.</summary>

✅ <b>Correct!</b> Correct! Stepping through a loop with a breakpoint allows you to observe variables changing step-by-step.
</details>

<details>
<summary><b>Option D:</b> It prevents the loop from running out of bounds.</summary>

❌ <b>Incorrect!</b> Breakpoints only pause execution; they cannot modify bounds checking.
</details>
