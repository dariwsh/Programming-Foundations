## 🧠 Interactive Quiz

**Question:** Which of the following is true about C++ reference variables?

<details>
<summary><b>Option A:</b> They must be initialized when declared and cannot be reassigned to reference a different variable.</summary>

✅ <b>Correct!</b> Correct! References are aliases and must be initialized immediately; they cannot change what variable they point to later.
</details>

<details>
<summary><b>Option B:</b> They can be uninitialized.</summary>

❌ <b>Incorrect!</b> References must be initialized on creation.
</details>

<details>
<summary><b>Option C:</b> They consume more memory than pointers.</summary>

❌ <b>Incorrect!</b> References are internally optimized and do not consume additional user-managed memory.
</details>

<details>
<summary><b>Option D:</b> They can be reassigned to different addresses like pointers.</summary>

❌ <b>Incorrect!</b> No, references cannot be rebound.
</details>
