## 🧠 Interactive Quiz

**Question:** Which operator is used to access structure members when using a structure pointer?

<details>
<summary><b>Option A:</b> The dot operator (.)</summary>

❌ <b>Incorrect!</b> The dot operator is used with structure objects directly, not pointers.
</details>

<details>
<summary><b>Option B:</b> The arrow operator (->)</summary>

✅ <b>Correct!</b> Correct! The arrow operator (->) dereferences the pointer and accesses the member in one step.
</details>

<details>
<summary><b>Option C:</b> The scope resolution operator (::)</summary>

❌ <b>Incorrect!</b> This is for namespaces and class structures, not pointers.
</details>

<details>
<summary><b>Option D:</b> The address-of operator (&)</summary>

❌ <b>Incorrect!</b> This returns a pointer address.
</details>
