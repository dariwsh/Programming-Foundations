## 🧠 Interactive Quiz

**Question:** What does 'Step Out' (Shift + F11) do in a debugger?

<details>
<summary><b>Option A:</b> It steps into the next inner function.</summary>

❌ <b>Incorrect!</b> Step Out exits, it doesn't step inside.
</details>

<details>
<summary><b>Option B:</b> It executes the remainder of the current function and pauses at its caller line.</summary>

✅ <b>Correct!</b> Correct! Step Out finishes running the current function immediately and pauses control right after the function return in the caller code.
</details>

<details>
<summary><b>Option C:</b> It deletes all breakpoints in the project.</summary>

❌ <b>Incorrect!</b> It has no impact on breakpoints.
</details>

<details>
<summary><b>Option D:</b> It restarts the entire debugging process.</summary>

❌ <b>Incorrect!</b> Restart is done via Ctrl+Shift+F5.
</details>
