## 🧠 Interactive Quiz

**Question:** Which C++ keyword is used to allocate memory on the heap, and which is used to release it?

<details>
<summary><b>Option A:</b> malloc and free</summary>

❌ <b>Incorrect!</b> These are C functions, not C++ keywords.
</details>

<details>
<summary><b>Option B:</b> new and delete</summary>

✅ <b>Correct!</b> Correct! 'new' dynamically allocates heap memory, and 'delete' releases it.
</details>

<details>
<summary><b>Option C:</b> alloc and dealloc</summary>

❌ <b>Incorrect!</b> These are not standard keywords in C++.
</details>

<details>
<summary><b>Option D:</b> create and destroy</summary>

❌ <b>Incorrect!</b> These do not exist in C++ memory management.
</details>
