## 🧠 Interactive Quiz

**Question:** When debugging, what is the difference between 'Step Into' (F11) and 'Step Over' (F10)?

<details>
<summary><b>Option A:</b> Step Into enters the function, while Step Over executes it without stepping inside.</summary>

✅ <b>Correct!</b> Correct! Step Into (F11) goes inside the function definition, while Step Over (F10) runs it as a single step without showing inside code.
</details>

<details>
<summary><b>Option B:</b> Step Over terminates program execution.</summary>

❌ <b>Incorrect!</b> Neither step command terminates execution.
</details>

<details>
<summary><b>Option C:</b> Step Into skips the current line of code.</summary>

❌ <b>Incorrect!</b> Step Into executes the current line, stepping inside if it's a function call.
</details>

<details>
<summary><b>Option D:</b> There is no difference.</summary>

❌ <b>Incorrect!</b> They behave differently when executing function calls.
</details>
