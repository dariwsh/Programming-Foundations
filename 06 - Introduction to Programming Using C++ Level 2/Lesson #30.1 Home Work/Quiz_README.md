## 🧠 Interactive Quiz

**Question:** What is the difference between vector size and vector capacity?

<details>
<summary><b>Option A:</b> Size is the number of elements it currently holds; capacity is the total elements it can hold before resizing.</summary>

✅ <b>Correct!</b> Correct! Size is the actual number of elements, while capacity is the amount of allocated storage room.
</details>

<details>
<summary><b>Option B:</b> Capacity is the number of elements it holds; size is the memory usage in bytes.</summary>

❌ <b>Incorrect!</b> Size is element count, not byte count.
</details>

<details>
<summary><b>Option C:</b> They are always equal.</summary>

❌ <b>Incorrect!</b> Capacity is often larger than size to minimize reallocations.
</details>

<details>
<summary><b>Option D:</b> There is no difference in C++.</summary>

❌ <b>Incorrect!</b> C++ distinguishes them through vector.size() and vector.capacity().
</details>
