## 🧠 Interactive Quiz

**Question:** How do you format a float to print exactly 3 decimal places using `printf`?

<details>
<summary><b>Option A:</b> printf("%.3f", value);</summary>

✅ <b>Correct!</b> Correct! The '.3' inside '%f' specifies exactly three digits of precision after the decimal point.
</details>

<details>
<summary><b>Option B:</b> printf("%3f", value);</summary>

❌ <b>Incorrect!</b> This specifies a minimum field width of 3, not the decimal precision.
</details>

<details>
<summary><b>Option C:</b> printf("%f3", value);</summary>

❌ <b>Incorrect!</b> This prints the number followed by the character '3'.
</details>

<details>
<summary><b>Option D:</b> printf("%f.3", value);</summary>

❌ <b>Incorrect!</b> This is invalid syntax for precision formatting.
</details>
