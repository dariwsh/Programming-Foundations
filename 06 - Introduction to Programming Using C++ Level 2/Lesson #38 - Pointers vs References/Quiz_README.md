## 🧠 Interactive Quiz

**Question:** What is a main structural difference between pointers and references?

<details>
<summary><b>Option A:</b> Pointers cannot be null, references can.</summary>

❌ <b>Incorrect!</b> Pointers CAN be null, references cannot be null in safe standard C++.
</details>

<details>
<summary><b>Option B:</b> Pointers can be reassigned to point to different addresses, whereas references cannot be rebound.</summary>

✅ <b>Correct!</b> Correct! Pointers are flexible and can change targets; references are static aliases initialized once.
</details>

<details>
<summary><b>Option C:</b> References require dereference operators (*) to access values.</summary>

❌ <b>Incorrect!</b> References are accessed transparently without operators.
</details>

<details>
<summary><b>Option D:</b> Pointers cannot point to structures.</summary>

❌ <b>Incorrect!</b> Pointers can point to structures and classes.
</details>
