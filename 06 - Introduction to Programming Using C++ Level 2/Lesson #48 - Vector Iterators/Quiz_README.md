## 🧠 Interactive Quiz

**Question:** What does `vec.end()` return?

<details>
<summary><b>Option A:</b> An iterator pointing to the last element of the vector.</summary>

❌ <b>Incorrect!</b> No, that would be active element or end() - 1.
</details>

<details>
<summary><b>Option B:</b> An iterator pointing to the theoretical element past the last element of the vector.</summary>

✅ <b>Correct!</b> Correct! end() returns a boundary iterator pointing just after the last element. It is used as a stop condition in loops.
</details>

<details>
<summary><b>Option C:</b> The index of the last element.</summary>

❌ <b>Incorrect!</b> It returns an iterator object, not a numeric index.
</details>

<details>
<summary><b>Option D:</b> The value of the last element.</summary>

❌ <b>Incorrect!</b> It returns an iterator, not a value.
</details>
