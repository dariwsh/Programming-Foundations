## 🧠 Interactive Quiz

**Question:** Which combination of format specifiers is correct for printing a C-style string and a char in `printf`?

<details>
<summary><b>Option A:</b> %c and %s</summary>

❌ <b>Incorrect!</b> %c is for char and %s is for string, which is reversed.
</details>

<details>
<summary><b>Option B:</b> %s and %c</summary>

✅ <b>Correct!</b> Correct! %s format specifier is for strings, and %c is for single characters.
</details>

<details>
<summary><b>Option C:</b> %d and %f</summary>

❌ <b>Incorrect!</b> These are for integers and floating points.
</details>

<details>
<summary><b>Option D:</b> %str and %ch</summary>

❌ <b>Incorrect!</b> These format specifiers do not exist in standard C++ printf.
</details>
