## 🧠 Interactive Quiz

**Question:** What is the benefit of loading custom database/structures into a `vector<stEmployee>`?

<details>
<summary><b>Option A:</b> It speeds up program compilation.</summary>

❌ <b>Incorrect!</b> It has no impact on compilation.
</details>

<details>
<summary><b>Option B:</b> It allows safe, dynamic management and modification of records in memory.</summary>

✅ <b>Correct!</b> Correct! Managing records in a vector of structures is highly flexible and dynamically handles variable records count.
</details>

<details>
<summary><b>Option C:</b> It automatically encrypts employee data.</summary>

❌ <b>Incorrect!</b> Vectors do not perform automatic encryption.
</details>

<details>
<summary><b>Option D:</b> It bypasses standard C++ structures.</summary>

❌ <b>Incorrect!</b> It actually uses standard structures.
</details>
