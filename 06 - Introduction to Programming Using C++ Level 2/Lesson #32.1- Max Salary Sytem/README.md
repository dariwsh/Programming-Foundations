# 🎯 Main Idea

A C++ program that:

* Stores employee data using `vector` + `struct`
* Finds the employee with the highest salary
* Displays the result

---

# 🧠 Concepts Used

* `vector<struct>`
* `push_back()`
* Looping through objects
* Comparison logic

---

# 🔹 Data Structure

```cpp
struct stEmployee {

    string LastName;
    float Salary;
};
```

# ✨ Key Features & Tools
