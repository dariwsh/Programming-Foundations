## 🧠 Interactive Quiz

**Question:** Which format specifier is used to print signed integers using `printf`?

<details>
<summary><b>Option A:</b> %f</summary>

❌ <b>Incorrect!</b> %f is used for floats and doubles.
</details>

<details>
<summary><b>Option B:</b> %c</summary>

❌ <b>Incorrect!</b> %c is used for characters.
</details>

<details>
<summary><b>Option C:</b> %d or %i</summary>

✅ <b>Correct!</b> Correct! %d or %i represents a decimal signed integer in printf formatting.
</details>

<details>
<summary><b>Option D:</b> %s</summary>

❌ <b>Incorrect!</b> %s is used for strings.
</details>
