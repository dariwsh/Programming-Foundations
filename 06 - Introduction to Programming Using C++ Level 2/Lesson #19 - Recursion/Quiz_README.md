## 🧠 Interactive Quiz

**Question:** What is the critical rule to prevent infinite recursion in a recursive function?

<details>
<summary><b>Option A:</b> You must use a loop inside the function.</summary>

❌ <b>Incorrect!</b> Recursion replaces explicit loops; it doesn't require loops internally.
</details>

<details>
<summary><b>Option B:</b> You must define a base case that stops the recursion.</summary>

✅ <b>Correct!</b> Correct! A base case is the stopping condition that stops further recursive calls and unwinds the stack.
</details>

<details>
<summary><b>Option C:</b> The function must return void.</summary>

❌ <b>Incorrect!</b> Recursive functions can return any type.
</details>

<details>
<summary><b>Option D:</b> You must allocate memory on the heap.</summary>

❌ <b>Incorrect!</b> Recursion utilizes stack frame memory, not heap memory allocation.
</details>
