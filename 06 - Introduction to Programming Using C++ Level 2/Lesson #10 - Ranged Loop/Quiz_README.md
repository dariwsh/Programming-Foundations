## 🧠 Interactive Quiz

**Question:** What does a range-based for loop `for (int val : numbers)` do?

<details>
<summary><b>Option A:</b> It iterates a pointer through numbers.</summary>

❌ <b>Incorrect!</b> It iterates values directly, not pointers.
</details>

<details>
<summary><b>Option B:</b> It copies each element of 'numbers' into 'val' one by one during iteration.</summary>

✅ <b>Correct!</b> Correct! A ranged loop iterates through all elements of a container, making copies unless references (int& val) are used.
</details>

<details>
<summary><b>Option C:</b> It prints the index of elements.</summary>

❌ <b>Incorrect!</b> Ranged loop works with values, not indices.
</details>

<details>
<summary><b>Option D:</b> It runs the loop in reverse order.</summary>

❌ <b>Incorrect!</b> Ranged loops iterate forward by default.
</details>
