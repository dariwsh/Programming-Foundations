## 🧠 Interactive Quiz

**Question:** What is the return type and output of `isdigit('A')` in C++?

<details>
<summary><b>Option A:</b> Returns true (non-zero) because 'A' is a letter.</summary>

❌ <b>Incorrect!</b> isdigit checks for numbers 0-9; 'A' is not a digit.
</details>

<details>
<summary><b>Option B:</b> Returns false (0) because 'A' is not a numerical digit.</summary>

✅ <b>Correct!</b> Correct! isdigit returns 0 (false) for non-numeric characters.
</details>

<details>
<summary><b>Option C:</b> Returns the ASCII value of 'A'.</summary>

❌ <b>Incorrect!</b> It returns a boolean-like int, not ASCII values.
</details>

<details>
<summary><b>Option D:</b> Raises a compilation error.</summary>

❌ <b>Incorrect!</b> Passing 'A' is safe and valid.
</details>
