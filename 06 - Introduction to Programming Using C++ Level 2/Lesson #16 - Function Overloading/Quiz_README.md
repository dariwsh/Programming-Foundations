## 🧠 Interactive Quiz

**Question:** How does the C++ compiler distinguish overloaded functions?

<details>
<summary><b>Option A:</b> By their return types only.</summary>

❌ <b>Incorrect!</b> C++ does not overload functions based on return type alone.
</details>

<details>
<summary><b>Option B:</b> By their names only.</summary>

❌ <b>Incorrect!</b> Overloaded functions share the same name.
</details>

<details>
<summary><b>Option C:</b> By their parameter list (type, number, or order of arguments).</summary>

✅ <b>Correct!</b> Correct! Overloading is distinguished by the unique list of argument types, counts, or order (signature).
</details>

<details>
<summary><b>Option D:</b> By their variable names.</summary>

❌ <b>Incorrect!</b> Variable names do not affect function overloading.
</details>
