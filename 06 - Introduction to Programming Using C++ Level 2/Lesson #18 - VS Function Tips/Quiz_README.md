## 🧠 Interactive Quiz

**Question:** Which shortcut opens the Peek Definition window in Visual Studio?

<details>
<summary><b>Option A:</b> Alt + F12</summary>

✅ <b>Correct!</b> Correct! Alt + F12 opens Peek Definition, displaying function code without opening a new file tab.
</details>

<details>
<summary><b>Option B:</b> F5</summary>

❌ <b>Incorrect!</b> F5 is used to start debugging.
</details>

<details>
<summary><b>Option C:</b> Ctrl + F</summary>

❌ <b>Incorrect!</b> Ctrl + F opens the search dialog.
</details>

<details>
<summary><b>Option D:</b> F11</summary>

❌ <b>Incorrect!</b> F11 is Step Into during debugging.
</details>
