## 🧠 Interactive Quiz

**Question:** Which function removes all elements from a vector, making its size 0?

<details>
<summary><b>Option A:</b> pop_back()</summary>

❌ <b>Incorrect!</b> pop_back() only removes the last single element.
</details>

<details>
<summary><b>Option B:</b> clear()</summary>

✅ <b>Correct!</b> Correct! clear() removes all elements, leaving the vector size at 0.
</details>

<details>
<summary><b>Option C:</b> empty()</summary>

❌ <b>Incorrect!</b> empty() is a boolean query function; it does not modify the vector.
</details>

<details>
<summary><b>Option D:</b> erase()</summary>

❌ <b>Incorrect!</b> erase() removes elements at specific iterator positions, not all elements (unless end/begin boundaries are passed).
</details>
