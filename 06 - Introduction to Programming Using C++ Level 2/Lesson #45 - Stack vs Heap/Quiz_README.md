## 🧠 Interactive Quiz

**Question:** What is a major difference between Stack and Heap memory?

<details>
<summary><b>Option A:</b> Stack is slow and manual; Heap is automatic and fast.</summary>

❌ <b>Incorrect!</b> It is the opposite; Stack is fast/automatic, Heap is slower/manual.
</details>

<details>
<summary><b>Option B:</b> Stack is managed automatically by the compiler; Heap must be managed manually by the programmer using new/delete.</summary>

✅ <b>Correct!</b> Correct! Stack variables are pushed and popped automatically when entering/exiting scopes. Heap variables require manual allocation and deallocation.
</details>

<details>
<summary><b>Option C:</b> Heap is of fixed size; Stack is unlimited.</summary>

❌ <b>Incorrect!</b> Stack has a small limited size (usually 1-2MB), whereas Heap is limited only by physical RAM.
</details>

<details>
<summary><b>Option D:</b> There is no performance difference.</summary>

❌ <b>Incorrect!</b> Stack access is much faster due to hardware support.
</details>
