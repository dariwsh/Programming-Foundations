## 🧠 Interactive Quiz

**Question:** Which method adds a new element to the end of a std::vector?

<details>
<summary><b>Option A:</b> push()</summary>

❌ <b>Incorrect!</b> push() is used in std::stack, not std::vector.
</details>

<details>
<summary><b>Option B:</b> push_back()</summary>

✅ <b>Correct!</b> Correct! push_back() inserts a new element at the very end of the vector.
</details>

<details>
<summary><b>Option C:</b> insert_end()</summary>

❌ <b>Incorrect!</b> insert_end() is not a member of std::vector.
</details>

<details>
<summary><b>Option D:</b> append()</summary>

❌ <b>Incorrect!</b> append() is for std::string, not std::vector.
</details>
