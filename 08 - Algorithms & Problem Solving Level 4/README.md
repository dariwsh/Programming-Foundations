## ▶️ How to Run

Each folder is a standalone Visual Studio project. Open the `.slnx` file in Visual Studio 2022 or later and press **Ctrl + F5**, or compile the `.cpp` file directly:

```bash
g++ -std=c++17 "file.cpp" -o app && ./app
```
