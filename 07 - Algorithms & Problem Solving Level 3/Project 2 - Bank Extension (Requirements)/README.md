# 🏦 Project 2: Bank System (Version 2 - Extension Requirements)

This directory contains the **Bank System with Transaction Capabilities** requirements and implementation files.

---

## 📋 Features

All features of **Bank System (Version 1)**, plus a dedicated **Transactions Menu**:
- **Deposit:** Adds a positive amount to a client's account balance.
- **Withdraw:** Withdraws money from a client's balance (checks for overdraft limits).
- **Total Balances:** Lists all client balances in a tabular format and sums the total funds in the bank.
- **Main Menu:** Navigates back to the main client administration system.

---

## 💡 Key Concepts

- **Menu Hierarchies:** Nested console state machines (Main Menu & Transactions Menu).
- **Data Persistence:** Updating specific transaction details inline and rewriting the client file.
- **Input Validation:** Checking balance sufficiency before allowing withdrawals.
- **Formatted Data Tables:** Displaying totals and balances neatly.

---

## 🚀 How to Run

1. Open the project solution file `Project 2 - Bank Extension (Requirements).slnx` (or `.vcxproj`) in Visual Studio.
2. Compile and run the application.
