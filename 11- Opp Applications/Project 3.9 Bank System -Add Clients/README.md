## 📖 Overview

Interactive UI screen class handling user input, duplicate account checks, and client creation flow.

## 🎯 Key Concepts & Implementation Highlights

- `clsAddNewClientScreen::ShowAddNewClientScreen()` implementation
- Prompting and reading client attributes with validation
- Displaying operation status cards upon successful save
