## 📖 Overview

Encapsulates the client list presentation inside a dedicated UI screen class inheriting from `clsScreen`.

---

## 🎯 Key Concepts & Implementation Highlights

- UI Screen Specialization through Inheritance (`clsClientListScreen : protected clsScreen`)
- Private rendering helper methods for table rows
- Screen title, sub-title, and record count indicators

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsClientListScreen.h`, `clsBankClient.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
