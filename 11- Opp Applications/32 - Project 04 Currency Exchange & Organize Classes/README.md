## 📖 Overview

The ultimate milestone of the course. Integrates the full Bank Management System with the all-new Currency Exchange Platform, complete with transfer logs, login registries, lockout protection, encrypted credentials, and a structured Clean Filter Architecture.

---

## 🎯 Key Concepts & Implementation Highlights

- Multi-Tier Clean Architecture (Core, Lib, Screens / Client, User, Currency)
- Currency Exchange Engine (`clsCurrency` with USD base conversion rate calculations)
- Currencies List, Find, Update Rate, and Currency Calculator Screens
- Account-to-Account Transfers (`clsTransferScreen`) with Balance Invariance Checks
- Auditing & Logging Subsystems (`LoginRegister.txt`, `TransferLog.txt`)
- Security Lockout System (3 failed login attempts lockout)
- Visual Studio Filter Organization for scalable enterprise C++ projects

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsCurrency.h`, `clsCurrencyExchangeMainScreen.h`, `clsCurrencyCalculatorScreen.h`, `clsTransferScreen.h`, `clsTransferLogScreen.h`, `clsLoginRegisterScreen.h`, `clsBankClient.h`, `clsUser.h`, `clsDate.h`, `clsUtil.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
