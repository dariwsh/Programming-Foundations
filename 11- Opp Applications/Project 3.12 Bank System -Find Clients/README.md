## 📖 Overview

Interactive UI screen to search for a client by account number and print a formatted client profile card.

---

## 🎯 Key Concepts & Implementation Highlights

- `clsFindClientScreen::ShowFindClientScreen()` implementation
- Account verification and non-existent record handling
- Reused `_PrintClient(clsBankClient)` helper method

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsFindClientScreen.h`, `clsBankClient.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
