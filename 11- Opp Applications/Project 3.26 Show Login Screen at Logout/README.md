## 📖 Overview

Refactored the application entry point `main()` into an infinite re-authentication loop allowing seamless user switching.

---

## 🎯 Key Concepts & Implementation Highlights

- Entry Point Loop Design in `main()`
- Continuous application lifecycle without terminal termination
- Encapsulation of the login loop inside `clsLoginScreen::ShowLoginScreen()`

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `Project 3 -Bank System.cpp`, `clsLoginScreen.h`, `Global.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns
