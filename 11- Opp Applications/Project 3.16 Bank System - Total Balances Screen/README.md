## 📖 Overview

Dedicated UI screen presenting all client account balances in a structured table, accompanied by total bank equity.

---

## 🎯 Key Concepts & Implementation Highlights

- `clsTotalBalancesScreen::ShowTotalBalances()` implementation
- Tabular client balance visualization
- Integrated number-to-words currency conversion footer

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsTotalBalancesScreen.h`, `clsBankClient.h`, `clsUtil.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
