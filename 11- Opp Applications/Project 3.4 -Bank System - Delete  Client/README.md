## 📖 Overview

Implements client deletion by marking objects for deletion and rewriting the storage file without the deleted record.

---

## 🎯 Key Concepts & Implementation Highlights

- `clsBankClient::Delete()` method execution
- Soft/Hard deletion patterns in flat-file architectures
- Resetting deleted object instance to `EmptyMode` state
- Dynamic vector filtering and atomic file rewriting

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsBankClient.h`, `clsPerson.h`, `clsString.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
