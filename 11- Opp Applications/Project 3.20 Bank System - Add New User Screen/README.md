## 📖 Overview

Interactive UI screen allowing administrators to create new bank users and assign granular bitwise permissions.

---

## 🎯 Key Concepts & Implementation Highlights

- Interactive Bitwise Permission Assignment (`_ReadPermissionsToSet()`)
- Full Access (`-1 / eAll`) vs Custom Permission Flag composition (`|` bitwise OR)
- Username uniqueness validation

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsAddNewUserScreen.h`, `clsUser.h`, `clsInputValidate.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
