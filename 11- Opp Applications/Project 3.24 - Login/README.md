## 📖 Overview

Introduces user authentication, credential validation against `Users.txt`, and session state management using a global `CurrentUser` object.

---

## 🎯 Key Concepts & Implementation Highlights

- Authentication Pipeline (`clsUser::Find(Username, Password)`)
- Global Session State (`Global.h` with `clsUser CurrentUser`)
- Login failure handling and retry loop
- Transition to `clsMainScreen` upon successful authentication

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsLoginScreen.h`, `clsUser.h`, `Global.h`, `clsMainScreen.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
