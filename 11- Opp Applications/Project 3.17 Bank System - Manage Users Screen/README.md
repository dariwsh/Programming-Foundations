## 📖 Overview

Administrative navigation menu screen dedicated to managing bank staff user accounts and permissions.

---

## 🎯 Key Concepts & Implementation Highlights

- Administrative Subsystem Navigation (`enManageUsersMenueOptions`)
- Dispatcher for User Management operations (List, Add, Delete, Update, Find)
- Base layout consistency with `clsScreen`

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsManageUsersScreen.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
