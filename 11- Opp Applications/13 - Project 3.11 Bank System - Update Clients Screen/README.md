## 📖 Overview

Dedicated UI screen to search for an existing client and update their personal information, PIN, and balance.

---

## 🎯 Key Concepts & Implementation Highlights

- `clsUpdateClientScreen` implementation
- Selective attribute editing with live preview card
- Save verification and feedback messaging

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsUpdateClientScreen.h`, `clsBankClient.h`, `clsInputValidate.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.

3. Build and run the project (`Ctrl + F5` or `F5`).
