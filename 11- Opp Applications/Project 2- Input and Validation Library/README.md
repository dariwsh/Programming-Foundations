## 📖 Overview

A robust, fail-safe input validation library designed to handle user inputs gracefully, validate types, check numeric and date ranges, and prevent infinite console input loops caused by invalid stream states.

---

## 🎯 Key Concepts & Implementation Highlights

- Robust Stream Input Validation (`std::cin.fail()`, `cin.clear()`, `cin.ignore()`)
- Template Function Implementation for Generic Number and Range Checks
- Date Validation & Range Verification using `clsDate`
- Static Design Pattern for seamless reusability across all application screens

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsInputValidate.h` — Static input and boundary validation engine.
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
