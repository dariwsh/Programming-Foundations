## 📖 Overview

A comprehensive static C++ utility library providing essential helper functions for everyday software engineering tasks, such as random data generation, cryptography/encryption, array manipulations, and string formatting.

---

## 🎯 Key Concepts & Implementation Highlights

- Static Class Design Pattern (no instance instantiation required)
- Pseudorandom Number Generation & Seed Management (`srand`, `rand`)
- String Encryption and Decryption using Symmetric Caesar Cipher
- Array Shuffling, Swapping, and Fill Operations
- Random Key and Token Generation (Keys, PINs, Passwords)

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsUtil.h` — Static utility helper library with generic and practical utility methods.
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
