## 📖 Overview

Financial transaction UI screen allowing bank staff to credit client accounts safely.

---

## 🎯 Key Concepts & Implementation Highlights

- `clsBankClient::Deposit(Amount)` domain method
- Positive amount validation and deposit confirmation prompts
- Immediate persistent balance update and updated balance display

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsDepositScreen.h`, `clsBankClient.h`, `clsInputValidate.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
