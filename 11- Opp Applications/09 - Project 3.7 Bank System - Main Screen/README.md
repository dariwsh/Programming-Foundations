## 📖 Overview

Introduces the Presentation Layer (UI Screens) and establishes the abstract base `clsScreen` class for consistent headers and layout formatting.

---

## 🎯 Key Concepts & Implementation Highlights

- Separation of Presentation Layer (Screens) from Domain Logic (Core)
- `clsScreen` Base Class with protected `_DrawScreenHeader()`
- `clsMainScreen` Hub with enum-based option dispatching (`enMainMenueOptions`)
- Modular screen architecture

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsMainScreen.h`, `clsInputValidate.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.

3. Build and run the project (`Ctrl + F5` or `F5`).
