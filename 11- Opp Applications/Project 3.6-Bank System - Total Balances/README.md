## 📖 Overview

Calculates the total balances across all bank accounts and formats balance summaries for executive review.

---

## 🎯 Key Concepts & Implementation Highlights

- `clsBankClient::GetTotalBalances()` aggregate business calculation
- Iterative aggregation over domain collections
- Financial number-to-words representation using `clsUtil::NumberToText`
- High-precision balance formatting

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsBankClient.h`, `clsUtil.h`, `clsPerson.h`, `clsString.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
