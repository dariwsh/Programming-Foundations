## 📖 Overview

Implementation of the core client domain model (`clsBankClient`) with data persistence integration and the `Find` query method.

---

## 🎯 Key Concepts & Implementation Highlights

- Domain Model Architecture (`clsBankClient` inheriting from `clsPerson`)
- Separation of Business Logic from Data Storage
- File Parsing (Line Record Serialization / Deserialization with delimiters)
- Empty vs Valid Object State Handling (`_GetEmptyClientObject()` and `IsEmpty()`)

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsBankClient.h`, `clsPerson.h`, `clsString.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
