## 📖 Overview

Enhanced the universal screen header `_DrawScreenHeader()` to display the active logged-in username and the current formatted date on every screen.

---

## 🎯 Key Concepts & Implementation Highlights

- Dynamic Screen Headers powered by `clsDate::GetSystemDate()` and `CurrentUser.UserName`
- Universal presentation consistency across all menus and sub-screens
- Clean visual hierarchy and real-time status indication

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** `clsScreen.h`, `clsDate.h`, `Global.h`
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

---

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
