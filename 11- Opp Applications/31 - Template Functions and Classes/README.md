## 📖 Overview

Explores C++ Generic Programming, Template Functions, and Template Classes to write reusable, type-independent algorithms and data containers.

---

## 🎯 Key Concepts & Implementation Highlights

- Function Templates (`template <typename T>`) for generic operations (Swap, Max, Min, Print)
- Class Templates (`template <class T>`) for generic data modeling (e.g., generic Calculator, Pair, Dynamic Array)
- Compile-time type deduction and code generation (Monomorphization)
- Multiple template parameters (`template <class T, class U>`)

---

## 🗂️ Key Files & Architecture

- **Primary Classes / Headers:** Template functions and class implementations.
- **Environment:** Visual Studio (C++ / MSVC)
- **Design Pattern:** Object-Oriented Architecture & Clean Separation of Concerns

## 🚀 How to Run

1. Open the solution or project file (`.sln` / `.vcxproj`) in **Visual Studio**.
2. Set the configuration to **Debug** or **Release** (x64 / x86).
3. Build and run the project (`Ctrl + F5` or `F5`).
